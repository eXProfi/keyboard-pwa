РУССКАЯ КЛАВИАТУРА — OFFLINE PWA ДЛЯ IPAD

Файлы:
- index.html               — само приложение
- manifest.webmanifest     — параметры веб-приложения
- service-worker.js        — офлайн-кэш
- apple-touch-icon.png     — иконка для iPad
- icon-192.png
- icon-512.png
- icon-maskable-512.png

КАК УСТАНОВИТЬ НА IPAD

1. Разместите ВСЮ папку на HTTPS-хостинге.
   Подойдут GitHub Pages, Cloudflare Pages, Netlify и т.п.

2. Откройте адрес index.html на iPad именно в Safari.

3. Дождитесь полной загрузки страницы хотя бы один раз при наличии интернета.
   В этот момент Service Worker сохранит приложение для офлайн-работы.

4. В Safari нажмите:
   Поделиться -> На экран «Домой» / Add to Home Screen.

5. Запустите приложение с появившейся иконки.

6. После первого успешного открытия приложение может работать без интернета.

ВАЖНО:
- Service Worker требует HTTPS (либо localhost для разработки).
- Если просто открыть index.html напрямую из приложения «Файлы» через file://,
  Service Worker не сможет установиться.
- Приложение не использует внешние библиотеки, шрифты, сервер или API.
